# DealFlow web

Next.js 16, React and strict TypeScript. See the root README for setup, implementation scope and validation. `npm run dev` starts the web app; `/api/*` forwards to server-side `API_URL` (defaults to port 8000). The API owns all authorization.

Checks: `npm run lint`, `npm run typecheck`, `npm test`, `npm run build`, `npm run test:e2e`.
